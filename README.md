# 连续点击器 (Continuous Clicker)

一个跨平台的桌面应用程序，支持自定义按键连点功能。

## 🚀 功能特性

- **自定义按键绑定**：支持鼠标、键盘、组合键绑定
- **智能连点**：可设置延迟时间的连续点击
- **全局快捷键**：Command+F 开始，Command+G 停止
- **跨平台支持**：macOS、Windows
- **中文界面**：完整的中文用户界面

## 🛠️ 编译方法

### 快速编译（推荐）
```bash
# 给脚本执行权限
chmod +x build.sh

# 运行编译脚本
./build.sh
```

### 手动编译
```bash
# macOS
go build -o click main.go system_clicker.go config.go logger.go

# Windows
GOOS=windows GOARCH=amd64 go build -o click.exe main.go system_clicker.go config.go logger.go


```

## 📱 使用方法

1. **启动程序**：双击可执行文件或命令行运行
2. **设置延迟**：调整点击间隔时间（毫秒）
3. **绑定按键**：点击"绑定按键"按钮，按下要绑定的按键组合
4. **开始连点**：点击"开始连续点击"或使用快捷键 Command+F
5. **停止连点**：点击"停止连续点击"或使用快捷键 Command+G

## 🔑 支持的按键类型

- **鼠标**：左键、右键、中键
- **键盘**：单键、组合键
- **组合键**：Command+C、Shift+A、Ctrl+V 等

## ⚠️ 重要注意事项

### 🚨 权限设置（首次运行必需）

连续点击器需要系统级权限才能执行鼠标点击操作。在首次运行时，您可能会遇到权限不足的问题。

#### 🍎 macOS 权限设置

1. **打开系统偏好设置** → **安全性与隐私** → **隐私** → **辅助功能**
2. **解锁设置**：点击左下角的锁图标，输入管理员密码
3. **添加应用程序**：点击"+"按钮，选择"连续点击器"
4. **确认权限**：确保程序旁边的复选框已勾选
5. **重启程序**：关闭并重新启动程序

#### 🪟 Windows 权限设置

1. **以管理员身份运行**：右键点击程序图标，选择"以管理员身份运行"
2. **或设置程序属性**：右键 → 属性 → 兼容性 → 勾选"以管理员身份运行此程序"



### 🔧 故障排除

#### 常见问题

1. **"权限不足"错误**
   - 检查是否已授予辅助功能权限
   - 重启程序
   - 重启系统

2. **"命令执行失败"错误**
   - 检查系统是否支持相应功能
   - 确认必要工具已安装

3. **程序崩溃或无响应**
   - 检查系统资源使用情况
   - 确认程序版本兼容性

#### 获取帮助

如果遇到问题：
1. 查看程序日志文件 `clicker.log`
2. 检查系统错误日志
3. 联系技术支持

### 🆘 紧急停止

如果程序失控：
1. **使用快捷键**：按设定的停止快捷键
2. **强制退出**：使用任务管理器强制结束程序
3. **系统重启**：在极端情况下重启系统

### 📝 其他注意事项

- **安全性**：程序需要系统级权限，请确保从可信来源下载
- **隐私**：程序不会收集或传输任何个人信息
- **兼容性**：支持 macOS 10.14+、Windows 10+
